Windows x64 preview adding **Check & install updates** to the MWB tray icon's right-click menu.

Selecting it opens the main window and runs the existing updater, showing progress and results. The tray entry and window button share their busy state and prevent duplicate requests. Installer verification, preference preservation and automatic restart use the existing update flow.

To obtain this version, use **Check & install updates** in the current main window or download **MouseWithOutBorders-0.1.17-Setup.exe**. The portable ZIP and SHA-256 checksums are also included.
