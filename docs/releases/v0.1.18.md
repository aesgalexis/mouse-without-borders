Windows x64 preview preparing **Mouse, with out borders** for WinGet distribution.

- Uses the supported **.NET 10 LTS** runtime, bundled in both Setup.exe and the portable executable. No separate .NET installation is needed.
- Includes the **MIT license** in the installer and portable ZIP.
- Preserves the existing mouse-sharing, clipboard, local key remapping, startup and pairing logic.
- Adds package registration and silent installation/upgrade/uninstall verification for the WinGet package.
- Keeps published release downloads stable so package checksums do not change.

Install **MouseWithOutBorders-0.1.18-Setup.exe** on both PCs, or use the existing **Check & install updates** action. Preferences are retained. The installer remains unsigned. This release does not claim new physical two-PC acceptance results.
