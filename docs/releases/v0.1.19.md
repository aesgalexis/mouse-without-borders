Windows x64 preview adding **encrypted mouse sharing and stronger pairing**.

- All mouse events, clipboard transfers and session messages now use TLS 1.2 or 1.3. The pairing secret authenticates the other PC's certificate before any client proof is sent.
- New **MWB3-** codes contain 160 random bits. Old 8-character codes and legacy hexadecimal keys are replaced; obsolete saved remote codes are cleared. Other preferences are retained.
- Packet authentication is bound to direction and session, with sequence checks against replay. Clipboard chunks retain their additional AES-GCM encryption.
- Automated regressions check certificate substitution, forged greetings, invalid client proofs, TCP confidentiality, ciphertext tampering, reflection/replay, migration, timeout/cancellation, clipboard transfers and the pairing interface.

**Required upgrade:** install **MouseWithOutBorders-0.1.19-Setup.exe on both PCs**, or select **Check & install updates** on each PC. Then copy the receiver's new **MWB3-** code and enter it on the other PC once. Version 0.1.18 and earlier cannot connect to this version. There is no fallback to unencrypted mouse traffic.

Setup.exe includes .NET 10 LTS; the portable ZIP and SHA-256 checksums are also included. This remains an unsigned preview. Physical two-PC latency and Windows 10 Schannel acceptance remain manual checks; automated tests do not establish those results.
