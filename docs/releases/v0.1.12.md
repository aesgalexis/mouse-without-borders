Windows x64 preview with the 0.1.11 mouse/trackpad recovery fixes and update recovery for terminated instances.

- Send mouse input from a separate bounded worker, keeping Windows mouse capture responsive. Stop sharing when native output stalls or is rejected.
- Let local mouse/trackpad movement cancel pending cursor placements when the PC is local or receiving. Late placements cannot override recovery.
- **Ctrl+Alt+F12** stops sharing from the independent UI thread, including while MWB is hidden (the shortcut must be available in Windows).
- Do not block Setup on processes that already have a termination exit code. Retire a mapped old executable before writing its replacement.
- Recover abandoned or retained instance mutexes on startup; a genuinely running instance still prevents duplicate launches.

Update **both PCs** with **Check & install updates**, or download and run Setup.exe on each PC. Pairing, preferences and clipboard settings are retained. No protocol change.

Automated Windows compilation, transport, UI/recovery, keyboard, clipboard and installer checks run before publication. Physical two-PC verification of the reported freeze remains pending. Installer, portable ZIP and SHA-256 checksums are included.
