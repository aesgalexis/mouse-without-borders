Windows x64 preview with tray icon visibility and connection status.

- On Windows 11, **Keep icon visible next to clock** is enabled by default. MWB reapplies the preference when Explorer recreates the taskbar. The tray menu saves your choice and opens Windows taskbar settings for manual control.
- The icon is gray while MWB is disconnected, listening or retrying. It turns blue when an authenticated sharing session connects and returns to gray when the connection ends.
- Existing MWB3 pairings from 0.1.19 continue to work.

The per-user installer, portable ZIP and SHA-256 checksums are included.
