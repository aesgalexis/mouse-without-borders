The updater retries through GitHub's API if the direct release download returns a server error such as HTTP 504. It checks the installer size and SHA-256 before running Setup.

If your current MWB version or browser shows HTTP 504, use the [PowerShell installer](https://github.com/aesgalexis/mouse-without-borders/blob/v0.1.24/scripts/install.ps1) to download and verify Setup through the GitHub API. Save the script, then run it in PowerShell from the folder where you saved it.

Install this release on both PCs to use confirmed mouse sharing. You can reuse existing MWB3 pairing codes.
