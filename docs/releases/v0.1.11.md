Windows x64 preview addressing loss of local mouse/trackpad control after a handoff.

- Native mouse output runs on a separate, bounded worker so the capture thread can keep processing Windows input notifications.
- Local mouse and trackpad movement immediately cancels pending remote cursor placements when the PC is local or receiving. Late placements cannot overwrite that recovery.
- Stalled or rejected native output stops the affected sharing session. Normal shutdown preserves queued releases for buttons pressed remotely.
- **Ctrl+Alt+F12** stops sharing on this PC from the independent UI thread, including when MWB is hidden in the notification area. The shortcut must be available in Windows.

Update **both PCs** using **Check & install updates**, or download and run the per-user Setup.exe on each PC. Pairing, preferences, key mappings and clipboard settings are retained. The protocol is unchanged.

The release pipeline checks Windows compilation, transport, input ownership, blocked-output recovery, UI, keyboard, clipboard and installer upgrades. Physical two-PC acceptance of the reported freeze remains to be verified with this build. Installer, portable ZIP and SHA-256 checksums are included.
