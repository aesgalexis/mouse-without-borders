Windows x64 release with confirmed mouse sharing.

- The window and tray show **Connected** after both PCs confirm mouse sharing is ready. Waiting, connecting and reconnecting have distinct states.
- If the other PC is unavailable, MWB prompts you to open it there and select **Start receiving**. Automatic retries follow the saved preference.
- Clipboard sharing waits for mouse readiness, including when enabled during connection setup.

Install this version on both PCs. Existing MWB3 pairing codes remain valid.

The per-user installer, portable ZIP and SHA-256 checksums are included.
