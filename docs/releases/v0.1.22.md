Windows x64 preview with connection controls in the tray.

- **Connect** starts the saved connection or receiver. If the controller needs an address or pairing code, MWB opens the window and focuses that field.
- **Disconnect** is enabled during an active session. **Stop listening** and **Cancel connection** are available while MWB waits for the other PC.

The per-user installer, portable ZIP and SHA-256 checksums are included.
